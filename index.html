DASHBOARD UTAMA

Selamat Datang, User!

Anda telah berhasil masuk ke sistem Report Anugerah Graha Plasindo. Silakan pilih menu pada sidebar sebelah kiri untuk melihat atau mengelola laporan target divisi.

📌 Petunjuk Navigasi

Gunakan menu di sebelah kiri untuk masuk ke halaman input dan laporan masing-masing divisi:

  • Target Divisi Tahunan → Pilih submenu (AGPC, AGPS, atau AGP N) untuk mengelola target nominal dan breakdown area.
  • Laporan Harian Sales → Pilih submenu Upload Data Master untuk mengunggah file Excel omset/sales ke database.
  • History Transaksi & Laporan → Mengakses riwayat data penjualan dan omset.
